# XICOMA - Delivery System Mockup

Este projeto contém os mockups funcionais para todo o ecossistema XICOMA.

## Estrutura

- **Client App** (`/client`): Aplicativo para o usuário final pedir comida.
- **Restaurant App** (`/restaurant`): Aplicativo para o restaurante receber e gerir pedidos.
- **Courier App** (`/courier`): Aplicativo para o entregador.
- **Admin Panel** (`/admin`): Painel de gestão web.
- **Assets** (`/assets`): Estilos e scripts globais.
- **Mock Data** (`/mock-data`): Dados fictícios.

## Como Executar

Apenas abra o arquivo `index.html` na raiz do projeto em qualquer navegador moderno. Não é necessário servidor web, pois o sistema usa caminhos relativos.

## Funcionalidades Simuladas

- Navegação entre telas (SPA).
- Adição de itens ao carrinho.
- Simulação de Checkout com M-Pesa/e-Mola.
- Fluxo de status de pedido (Restaurante/Entregador).

## Tecnologias

- HTML5
- Bootstrap 5
- CSS Customizado
- JavaScript Vanilla
